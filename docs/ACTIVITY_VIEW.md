# 영상과 동기화된 동작 요약

영상 아래 **동작 요약**에서 왼쪽/오른쪽 그리퍼 개폐, 양팔의 목표 변화와 실제 움직임,
Torso의 실제 움직임, base 이동 명령과 위치 변화를 확인한다. 전체 관절 그래프를 펼치지 않아도 라벨 경계를 찾을 수 있다.
동작 그래프 없이 요약 카드만 표시해 영상과 Task 타임라인을 함께 보며 라벨링한다.
annotation은 자동 생성·수정하지 않는다.

- 그리퍼: 실측 개방도 10% 이하는 닫힘, 90% 이상은 열림, 나머지는 중간이다.
  Leju 원본 `/leju_claw_state`, `/leju_claw_command`의 `data.position`은 **0=열림, 100=닫힘**이다.
  이 원값을 `/100`한 기존 bag profile은 단위명이 `open_fraction_0_closed_1_open`이어도 실제로 닫힘 비율이다.
  동작 요약에서는 기록된 토픽·필드·배율을 확인해 `개방도=1-원값/100`으로 환산하며,
  변화 방향과 목표 개방도도 같은 기준으로 표시한다. 이미 개방도로 저장된 다른 schema는 뒤집지 않는다.
  이 처리는 보기 전용이며 기존 cache·annotation·Export 숫자나 schema를 수정하지 않는다.
  목표 개방도도 별도로 표시한다. 직전 약 0.25초 동안 2%p 초과로 변하면 열리는 중/닫히는 중으로 표시한다.
  미세한 음수·100% 초과 센서값은 보존하며 보기용 미터만 0–100%로 제한하고 원래 센서 %를 병기한다.
  개폐 표시는 물체 파지 성공을 판정하지 않는다.
  기존 bag cache에는 동일 토픽의 서로 다른 기록이 섞일 수 있어, 이 구성의 실측은 현재 구간의 원본 메시지를 다시 조회한다.
  140번 bag 44.57초에서는 약 92/94의 피드백과 0 값이 번갈아 기록돼 nearest 선택만으로 열림/닫힘이 튀었다.
  `Reached=[2,2]`, 속도·effort 모두 0, 위치 `[-0.71,0]`인 기록이 다른 percent 피드백과 5ms 이내로
  5쌍 이상 반복되고 해당 후보의 80% 이상에서 상충하는 경우에만 그 영점 기록을 보기에서 분리한다.
  `Reached` 상태 자체나 단독 0 값은 제외하지 않는다. 실제 피드백 누락은 명령값·보간으로 대신하지 않는다.
  불러오는 동안에는 ‘불러오는 중’, 조회 실패·원본 미연결 시에는 미기록으로 표시해 기존 혼합 cache로 되돌아가지 않는다.
  이 분리는 동작 요약에만 적용되며 기존 cache와 이미 Export된 학습 숫자는 변경하지 않는다.
  RWH 자동수집의 `/rwh/capture/claw_state`, `/rwh/capture/claw_cmd_hold`도 **0=열림, 100=닫힘**이다.
  RWH profile의 `display.gripper` 설정으로 같은 개방도 표시를 적용한다. 설정이 없는 기존 RWH cache도
  알려진 helper 토픽명으로 호환한다. helper 피드백은 이미 수집기에서 분리됐으므로 기존 혼합
  `/leju_claw_state` 원본 재조회·echo 분리 경로에 넣지 않는다. helper가 없거나 누락된 값을 명령으로 채우지 않는다.
  이 설정은 화면 전용이며 Export의 `/100` 숫자·feature 이름은 변경하지 않는다.
- 팔: 양팔 각각 7개 관절의 직전 약 0.25초 최대–최소 범위 중 최댓값을 사용한다.
  기본 0.5° 초과이면 목표 변경 또는 실제 움직임이다. 목표 유지도 기록된 명령이며,
  명령 변경만으로 실측 움직임을 추정하지 않는다. head는 이 요약에 포함하지 않는다.
- Torso: 무릎·다리·허리 pitch/yaw 4개 실측 관절의 직전 약 0.25초 최대–최소 범위 중 최댓값이다.
  팔과 같은 기본 0.5° 기준으로 **움직임 / 정지**만 표시한다. 명령이나 open-loop 추정값으로 대신하지 않는다.
  whole-body 데이터는 이름과 validity로 읽으며, 기존 팔 14축 bag cache는 다시 import하지 않는다.
  이 경우 현재 시점 주변 5초와 비교·정렬에 필요한 여유만 `/sensors_data_raw.joint_data.joint_q[0:4]`에서
  읽고 메모리에 재사용한다. 기존 영상의 bag receipt 기준과 state 허용 시간을 사용한다.
  첫 비교 구간, 누락 관절, 원본 미연결/변경은 판정 전·미기록으로 남긴다. 기존 cache·annotation·추출 작업은 수정하지 않는다.
- Base: 명령은 `/cmd_vel`의 평면 속도/회전 속도, 실측은 odom의 이전 위치·yaw와의 차이에서 계산한다.
  기본 2cm/s 또는 2°/s 초과를 이동으로 표시한다. whole-body LeRobot에서는 랙 상대 재구성 위치를
  사용하며 패널에 출처를 표시한다. odom reset이나 재구성 보정도 위치 변화로 보일 수 있다.
- **동작 판정 기준**에서 문턱값을 조정할 수 있다. 초기 비교 구간, 샘플 누락, validity=false,
  알 수 없는 feature 구성은 미기록/판정 전으로 남긴다. 누락 구간을 가로질러 움직임을 계산하지 않는다.

가져온 catalog의 정렬된 30FPS 등 원본 frame grid를 사용한다. 기존 bag profile의 nearest/previous,
허용 시간으로 동기화하며 별도 보간이나 원본 bag 재수집을 하지 않는다.
비교 창은 정수 프레임으로 반올림하므로 30FPS에서는 8프레임(약 0.267초)이다.
카메라 프레임이 표시된 후 같은 frame의 상태를 갱신한다. 따라서 재생 중 영상 표시가 늦더라도
아직 보이지 않는 미래 프레임의 판정을 먼저 보여주지 않는다.

지원 매핑은 `kuavo_5w`의 기존 arm14/gripper/base feature와 관절 이름이 지정된 whole-body schema다.
기존 캐시의 숫자 신호는 episode 단위로 읽어 브라우저에서 재사용한다.
캐시에 없는 Torso와 위 Leju 그리퍼 실측은 현재 5초 구간을 별도로 조회하며, 이전 요청이 끝난 뒤 최신 영상 구간을 읽는다.

## 카메라 보기 회전

각 카메라의 **180° 보기 / 원본 보기** 버튼은 그 카메라의 표시 방향만 바꾼다.
오른손목 카메라는 기본적으로 180° 회전해서 보여주며, 같은 접속 주소에서는 선택을 원본 식별자와 카메라별로 기억한다.
원본 파일, import cache의 이미지, annotation, Export 영상에는 회전이 적용되지 않는다.
