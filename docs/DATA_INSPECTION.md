# Raw bag · Export 데이터 미리보기

영상 아래 **원본 bag / Export 데이터 확인**을 펼친다. 두 보기는 서로 다른 데이터를 보여준다.
원본 파일·annotation은 수정하지 않으며 ROS master나 로봇 연결도 필요 없다.

## Raw bag 원본

1. 확인할 원본 bag과 episode를 선택한다.
2. **Raw bag 원본 → 원본 토픽 불러오기**를 누른다.
3. 검색으로 토픽을 고른다. Import profile에 지정하지 않았던 토픽도 조회한다.
4. 영상을 원하는 시점으로 이동한 뒤 **영상 현재 시점 조회**를 누른다.
   또는 `bag 시작부터 시각 (초)`를 직접 입력하고 **메시지 조회**를 누른다.
5. 메시지 트리를 펼쳐 원래 값을 확인한다. 숫자를 클릭하면 그래프 필드에 들어간다.
   예: `/sensors_data_raw`의 `joint_data.joint_q[0]`, `/kuavo_arm_traj`의 `position[0]`.
   **메시지 조회**를 다시 눌러 그 필드의 그래프를 갱신한다.

조회는 bag 시작부터의 **수신 시각** 기준으로, 요청 시각 이후 첫 메시지 최대 3개를 표시한다.
각 메시지의 bag 수신 ns와 header ns는 따로 표시한다. ns는 브라우저의 정밀도 손실을 막기 위해 문자열로 전달한다.
header가 없는 메시지는 `없음`으로 표시한다. 원래 숫자·단위를 그대로 보여주므로
팔 목표 `/kuavo_arm_traj.position`의 `90`은 degree이고 Export에서는 radian으로 바뀔 수 있다.

그래프는 해당 시점 전후 2초, 최대 10,000개 메시지 검사 / 400점 표시다.
보간·필터·단위 변환은 하지 않는다. 배열은 최대 128개, 이미지 바이트는 32개로 접어 표시하며
잘린 부분은 `_truncated`로 알린다. 영상은 기존 영상 플레이어로 확인한다.
LeRobot만 불러오고 원본 bag 연결이 없는 경우 Raw bag 조회는 제공되지 않는다.
연결된 bag 경로도 서버의 `--allow-root` 범위 안이어야 한다.

## Export 기준 미리보기

1. task 구간을 저장하고 오른쪽 **출력 구성**과 **저장 방식**을 고른다.
2. **데이터 미리보기 (저장 안 함)** 또는 검사 패널의 **Export 데이터 미리보기 계산**을 누른다.
   새 dataset의 이름은 이 단계에서 비워도 된다. 기존 dataset 추가/수정 모드는 대상 폴더를 지정한다.
3. 기존 누락 구간 검토 창이 나오면 보간·hold·제외 여부를 고른다. 새 구성을 위한 torso/랙 정보가 없다는 이유만으로
   새 차단 조건을 추가하지는 않는다. 해당 차원은 validity=0과 사유 코드로 표시한다.
4. 작업이 끝나면 선택 구간의 항목 이름·단위·원본·유효 비율·최소/최대·누락 사유가 열린다.
   카메라는 파일 존재와 승인된 이미지 hold를 확인한다. 전체 영상 디코딩·인코딩은 하지 않는다.
5. 영상을 탐색하거나 **영상 현재 시점 조회**를 눌러 그 프레임의 정확한 값·validity·사유를 확인한다.
   `정지·탐색 시 Export 값 자동 조회`는 영상 재생 중 매 프레임 계산하지 않고, 멈추거나 탐색했을 때 갱신한다.
6. 그래프에서 항목을 고른다. 최대 400점이며, 미기록·선택 제외 구간은 비워 표시한다.
   표의 현재 프레임 값은 샘플링하지 않는다. task 없는 프레임은 `Export 제외`로 표시한다.
7. 실제 저장하려면 이름/대상을 정하고 **설정 확인 후 Export**를 누른다.

새 구성에서는 실제 Export와 같은 함수로 state24/action23·단위 변환·다중 태그 기반 랙 상대 위치를 계산한다.
bag 전체를 기준으로 랙 anchor를 찾은 뒤 선택 구간을 확인하므로, clip 이후에 잘 보인 태그로 앞부분을 역산하는 것도 같다.
사용자가 승인한 보간·hold 구간은 별도 표시한다. **validity=0의 숫자 0은 실제 목표 명령 0이 아니다.**
항목 정의는 [Torso·랙 schema](WHOLEBODY_SCHEMA.md)를 참고한다.

## 실제 Export와의 관계

- 미리보기는 영상 파일이나 최종 LeRobot dataset을 만들지 않는다. 계산한 숫자 배열과 검사 snapshot만 `workspace/jobs/<id>/`에 저장한다.
- 같은 project revision·원본 파일 identity·schema·저장 방식·누락 처리·랙 보정이면 실제 Export가 미리 계산한 배열을 재사용한다.
  원본 identity는 기존 editor와 동일한 파일명/크기/수정시각 기준이며, 원본 내용을 전부 checksum하는 방식은 아니다.
- 편집/원본/설정이 바뀌면 다시 계산한다. 미리보기 연결을 해제하면 독립적으로 Export할 수도 있다.
  미리보기는 필수 조건이 아니다. 작업 목록에서 이전 완료 미리보기를 다시 열 수 있으며 오래된 revision은 표시한다.
- 추가 모드의 미리보기는 **이번에 추가할 선택 구간**을 보여준다. 기존 dataset 전체를 다시 검사하는 기능은 아니다.
- 카메라 metadata/파일 존재 검사는 전체 영상 무결성 검사를 대체하지 않는다. 영상 인코딩 시간도 여전히 실제 Export 때 필요하다.
- validity와 missing_reason은 GR00T loss에 자동 반영되지 않는다. 학습 시 mask 연결은 별도다.
- Raw bag 조회는 bag 메시지를 역직렬화하는 반면, 기존 `가져온 원본 catalog의 신호 보기`는 Import된 배열이다.
  Export 미리보기는 선택한 출력 schema로 다시 계산한 값이다. 세 보기를 혼동하지 않는다.

서버 업데이트 후에는 진행 중인 작업이 끝난 다음 서버를 재시작하고 브라우저를 새로고침한다.
원본 bag·기존 annotation·완료 dataset을 다시 가져오거나 다시 작성할 필요는 없다.
