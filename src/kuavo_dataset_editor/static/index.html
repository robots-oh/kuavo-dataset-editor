Export

왼쪽에서 Export할 원본을 선택하세요.

편집 트랙과 별도로 선택합니다. Goal Export는 Goal이 있는 구간만 사용하며 Step 라벨은 보존합니다.

새 구성은 원본 bag 전체에서 다시 계산합니다. 미기록 값은 validity=0·누락 사유와 함께 저장합니다. GR00T 학습에서는 mask를 별도로 연결해야 합니다. 기존 14차원 dataset에 새 구성을 추가할 수는 없습니다.

라벨 구간만 새 dataset으로 저장합니다. Hub에는 업로드하지 않습니다.

Hugging Face 업로드

완료된 로컬 dataset만 업로드합니다. 먼저 터미널에서 .venv/bin/hf auth login으로 로그인하세요.

기존 repo의 공개 범위는 바꾸지 않습니다. editor/ 이벤트·로컬 경로·원본 bag은 보내지 않습니다.

파일 선택

‘폴더 선택…’에서 폴더를 고르면 다음 다운로드 위치로 기억합니다. 브라우저에서는 --allow-root로 허용한 폴더만 보입니다. 데스크톱 상단 ‘SSH 저장 폴더…’로 다른 SSD를 허용할 수도 있습니다. 기존 bag·annotation은 이동하지 않으며, 진행 중인 작업에는 적용하지 않습니다.

받은 bag 저장 폴더 선택

에디터 서버가 실행되는 컴퓨터의 폴더입니다. 폴더를 열고 이 폴더에 저장을 누르세요. 기존 파일을 옮기거나 다운로드를 시작하지 않습니다.

원하는 폴더가 없으면 서버 실행 시 --allow-root /원하는/데이터폴더로 허용하세요. 브라우저 요청으로 접근 범위를 넓히지는 않습니다.

선택한 경로는 해당 workspace에 기억됩니다.

Export 전 누락 구간 확인

원본 bag·캐시·annotation은 바꾸지 않습니다. 상태값은 원본 메시지의 기록 시각으로 보간하고, 영상은 합성하지 않고 이전 실제 프레임을 재사용합니다. bag은 현재 profile의 수신 시각 기준이며, 누락 프레임 수와 앞뒤 메시지 시간 간격은 다를 수 있습니다.

긴 누락·급격한 동작 구간은 보정의 정확성을 보장할 수 없습니다. 제외를 선택하면 해당 시간의 모든 센서를 함께 제외하고 episode가 나뉠 수 있습니다. 보정 내역은 결과의 editor/quality.json에 저장됩니다.
